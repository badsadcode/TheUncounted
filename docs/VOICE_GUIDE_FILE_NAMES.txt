THE UNCOUNTED: voice file names for Coth and Eranu (for BadSad)

Coth and Eranu say each line's number on their recordings. Cut each line out
and name it as listed below, in assets/audio/voice/, as .ogg, .wav or .mp3.
The game plays nothing else, so convert any .m4a. Mono, 44.1 or 48 kHz, with
half a second of silence at the end. Scene files are named after whoever
starts the scene, so some of Coth's lines say 'eranu'; that's correct.


==============================================================================
THE REUNION CARDS NEED A LITTLE WORK
==============================================================================

The game plays one file per story card, and a voiced card turns by itself 1.4
seconds after its recording ends.

Card 3 has both voices, but the game plays only story.cothepoo.3. Join Coth's
line and Eranu's line into that one file, with a pause between them. The names
story.cothepoo.3.coth and story.cothepoo.3.eranu below are only labels, and
the game won't play them.

Cards 2 and 3 also carry description to read, so add silence to those files or
the card may turn too soon. Silence before the line works well: the player
reads about the hug first, then hears the shout.
