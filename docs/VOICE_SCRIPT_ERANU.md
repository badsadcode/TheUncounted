# Eranu: voice script

Every line Eranu says in the game, ready to read aloud. Save each recording as `assets/audio/voice/<file name>.ogg` (or `.wav` / `.mp3`), using the file name in the left column. The game plays it along with the subtitle. Lines without a recording just show as text, so record as many or as few as you like, a few at a time.

**How to record (no studio needed):** a phone or headset is fine. A quiet room (a wardrobe full of clothes is a famous trick), a hand's width from the mic, and half a second of silence at the end. Mono, 44.1 or 48 kHz. Have fun with it: shouting, laughing and ad-libs are all welcome.

**Eranu**: a brave, clever warrior from the Glens, in a green kilt with a targe and a sword. Speaks light Scots (aye, wee, ken, dinnae, hame). Confident, dry, secretly soft about Coth, whom she calls her waifu (and Cothepoo).
